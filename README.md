# Supply Chain Analytics – Power BI Dashboard

An interactive **Power BI report** developed to analyze supply chain performance and provide actionable business insights.

## 📊 Dashboard Overview

The report includes two main sections:

### 1. Analytics
Provides an overview of key supply chain KPIs and performance metrics, including:
- Total Revenue
- Total Products Sold
- Total Costs
- Average Profit Margin
- Stock Levels
- Revenue by Product Type, SKU, Customer Demographics, and Shipping Carrier
- Defect Rate Analysis

### 2. Cohort Analysis
Includes a **Customer Cohort Analysis** to visualize customer purchasing behavior and retention patterns over time.

## 🛠️ Tools & Technologies

- Power BI
- DAX
- Data Analysis
- Data Visualization
- Cohort Analysis

## 🎯 Project Objective

To transform supply chain data into **interactive and meaningful insights** that support better understanding of business performance and customer behavior.
